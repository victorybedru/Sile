# Testing Guide

## Backend Tests
Navigate to the server directory and run:

npm test

## Frontend Checks
From the project root, run:

npm run lint
npm run build

## Manual Testing
- Open the application.
- Submit a report with valid information.
- Verify that the report appears in the application.
- Check its synchronization status.
- Test report status updates.
- Review announcements.
- Test offline submission and synchronization after reconnecting.

Tests should be performed in a development environment.

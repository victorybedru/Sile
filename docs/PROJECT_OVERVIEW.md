# Sile

Sile is a community service information and reporting platform designed to help residents report local service problems and follow their progress.

## Core Features

- Submit community service reports.
- Track report status and progress.
- View public service announcements.
- Save reports locally when offline.
- Synchronize pending reports when connectivity returns.
- Support coordinator workflows for report assignment and resolution.

## Technology Stack

- Frontend: React, TypeScript, Vite and Tailwind CSS.
- Backend: Node.js, Express and TypeScript.
- Database: Supabase PostgreSQL.
- Offline storage: IndexedDB.

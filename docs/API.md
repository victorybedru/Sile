# API Overview

Base URL: http://localhost:5000/api/v1

## Reports
- GET /reports
- POST /reports
- POST /reports/sync
- GET /reports/:id
- GET /reports/:id/history
- PATCH /reports/:id/status
- PATCH /reports/:id/assign

## Announcements
The API provides endpoints for retrieving and managing announcements.

## Health Check
GET /health

The API uses JSON request and response bodies.
